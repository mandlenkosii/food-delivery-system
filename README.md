# Food Delivery System

## Description

A simple JavaScript application that uses Object-Oriented
Programming to manage food items and calculate delivery costs.

## Food Types

- Pizza
- Burger
- Drink
- Dessert

## OOP Principles

- Encapsulation: Private price and controlled access methods.
- Inheritance: Food types extend the Food class.
- Abstraction: The Order class hides calculation details.
- Polymorphism: Each food type has its own delivery fee.

## How to Run

1. Install Node.js.
2. Open the project folder in the terminal.
3. Run `npm start` to display the order.
4. Run `npm test` to execute the tests.
