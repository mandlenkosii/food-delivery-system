Encapsulation: “I used #price to make the price private. The getPrice() method allows me to access it.”

Inheritance: “Pizza, Burger, Drink, and Dessert extend the Food class, so they reuse its common properties and methods.”

Abstraction: “The Order class hides the calculation process. I can call getFinalTotal() instead of adding every price and delivery fee manually.”

Polymorphism: “Each food class has its own getDeliveryFee() method, so the same method returns a different fee for each type of food.”
